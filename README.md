# Task_TODO
Mern_Stack 


A simple and efficient Todo List application built with React, Node.js, Express.js, and MongoDB. This application allows users to create, read, update, and delete tasks, helping them stay organized.

# Features

-> Add new tasks

-> Mark tasks as completed

-> Edit tasks

-> Delete tasks

-> Responsive UI

# Tech Stack

Frontend:

React

Axios React Icons

Backend:

Node.js

Express.js

Database:

MongoDB

# Installation and Setup

Follow these steps to get the project up and running on your local machine.

# Prerequisites

Make sure you have the following installed:

Node.js: Download Node.js

MongoDB: Download MongoDB

Steps to Run the Project

Clone the repository

```bash
git clone <repository_url>
```

Navigate to the project directory

```bash 
cd 'Todo List
 ```

Install dependencies

```bash
npm install 
```

Install additional frontend dependencies

```bash
npm install axios react-icons
```

Start the development server

```bash
npm run dev
```

# Set up the MongoDB database

Make sure MongoDB is running locally or provide a connection string to a cloud-based MongoDB instance (e.g., MongoDB Atlas).

Update the backend configuration (e.g., .env file) with your MongoDB connection string. 

MONGO_URI=your_mongodb_connection_string
PORT=5000

#Usage

Open your browser and navigate to the application at http://localhost:5173.

Start adding tasks to organize your day!
